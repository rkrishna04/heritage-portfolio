# Heritage Portfolio

A personal developer portfolio inspired by **traditional Indian aesthetics** — terracotta, ochre, indigo, forest green, gold and marigold — blended with modern, responsive web design.

## Design Language

- **Color palette**: Earthy jewel tones on warm ivory / parchment backgrounds
- **Typography**: `Yatra One` + `Teko` for display / headings, `Poppins` for body
- **Motifs**: Subtle lattice (jali-inspired) background, Warli-inspired hero illustration, framed project cards that feel like archival mats
- **Sections**:
  - **Namaste** — narrative welcome
  - **Works / Collection** — filterable projects under *Chitra* (visual), *Kala* (systems & design), *Katha* (case studies)
  - **Craft** — philosophy of *karigari* (craftsmanship)
  - **Samvad** — welcoming contact

## Tech

- Pure HTML, CSS & vanilla JS (no build step)
- Fully responsive
- Accessible focus states & reduced-motion friendly interactions
- Ready for Vercel / Netlify / any static host

## Customize

1. Replace “Krishna” and the placeholder email / social links with your details.
2. Update the project cards in `index.html` with real work, screenshots or links.
3. Point the contact form to Formspree, Resend, or your own API.
4. Tweak CSS variables in `css/style.css` if you want to shift the palette.

## Deploy on Vercel

1. Push this repo (or fork it).
2. Import the repository on [vercel.com](https://vercel.com/new).
3. Framework Preset: **Other** (static). Root directory stays `/`.
4. Deploy — your site will be live at `*.vercel.app`.

Alternatively, from the Vercel CLI:

```bash
npx vercel
```

## Local preview

Just open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
